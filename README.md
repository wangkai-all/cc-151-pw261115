# 收入变动因素拆解分析

对两个期间的收入差额做三因素数值分解：**总销量、商品结构（销量占比）、单品成交价格**，
支持从总额逐层下钻到商品，点击任意贡献值查看参与计算的数量、均价与完整公式。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm test         # 12 项单元测试（恒等式 / Shapley 性质 / 筛选重算）
npm run build    # 类型检查 + 生产构建
```

## 拆解模型

仅对**两期均有正向销售的共同商品**，收入恒等式写为：

```
R_t = Q_t × Σ_i w_i,t × p_i,t
Q_t   = Σ q_i,t        总销量
w_i,t = q_i,t / Q_t    销量占比（商品结构）
p_i,t = 销售额 / 销量   成交均价
```

对总销量 V、结构 M、价格 P 三个因素枚举 **3! = 6 种全部替换顺序**，在每个顺序中依次把一个因素
由基期取值替换为当期取值，取替换前后的收入差作为该顺序下的边际贡献；每个因素取 6 个边际贡献的
**算术平均（Shapley 值）**。因此：

- 消除了人为选择计算顺序的影响；
- 三因素贡献加总**严格等于**共同商品的实际收入差（测试以 1e-6 容差校验，实际残差 ~1e-12）；
- 满足对称性、虚拟性（因素两期不变则贡献为 0）、可加性。

## 口径边界（按需求明确处理）

| 情形 | 处理 |
|---|---|
| 新增商品（无基期单价） | 单独列示当期收入，**不补零价**、不进入同品价格效应 |
| 退出商品（无当期单价） | 单独列示基期收入（取负），不进入三因素 |
| 退货 / 其他调整 | 不满足“量×价”结构，**独立核对**，只进净收入恒等式 |
| 门店 / 品类筛选 | 从原始事实在当前范围内**重新聚合**总量与结构；各分组因素贡献因基准不同**不可直接相加**（有专门测试） |
| 单商品下钻 | 结构占比 w≡1，结构效应恒为 0，销量+价格效应之和 = 单品收入差 |

## 结构悖论样本

样本内置“整体均价上升但每个单品都降价”：6 个共同商品单价全部低于基期，但高价的精品咖啡豆
销量占比由 13.5% 升至 31.4%，低价挂耳包占比由 40.5% 降至 20.9%，结构向高价商品倾斜，使共同商品
整体均价 87.84 → 107.41 元/件反升。页面用独立面板展示各品降价方向、整体均价反向及反事实检验。

## 免责

结果是对已发生收入差额的**数值分解**，回答“差额在数学上各由多少构成”，**不证明**价格或销量
变化的原因（因素间可能相互影响）。支持导出逐商品级 CSV（含三因素 Shapley 贡献、退货与调整列）。
